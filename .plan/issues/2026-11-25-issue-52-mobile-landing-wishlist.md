# 2026-11-25 — 모바일 랜딩 설명과 Wishlist 입력란 표시 수정

- Date: 2026-11-25
- GitHub Issue: #52

## Goal
휴대폰에서 QA 설명을 스크롤하며 읽고 키보드 위에서 이메일을 입력할 수 있다.

## Non-goals
히어로 지도와 데스크톱의 카메라 연출은 기존 동작을 유지한다.

## Context / Constraints
모바일 본문에도 데스크톱용 설명과 장식 지도가 함께 있다. 키보드를 열면 브라우저가 실제로 보여주는 영역만 줄어들 수 있다.

## Approach (Checklist)
- 모바일 본문의 장식 지도를 숨기고 기존 설명 목록을 한 열로 배치한다.
- 화면 밖으로 나간 본문을 다시 읽을 때 설명이 보이도록 한다.
- Wishlist를 보이는 영역에 맞추고 포커스된 입력란을 시트 안에서 스크롤한다.

## Validation
lint, typecheck, build 및 휴대폰 크기의 브라우저에서 본문과 입력란을 확인한다.

## Risks & Rollback
실기기의 키보드 동작은 브라우저마다 달라 별도 확인이 필요하다. 문제가 생기면 이 변경 커밋을 되돌린다.
