# 온보딩 모바일 레이아웃 수정

상태: 구현 완료

## 변경 범위

- 헤더 메뉴를 별도 행으로 배치하고 모바일 터치 영역을 확보했다.
- 소개 영역과 설치 단계의 여백, 제목 크기, 코드 복사 버튼 배치를 조정했다.
- grid 자식의 최소 너비와 이미지 최대 너비를 제한했다.

## 검증 결과

- `npm run build` 통과.
- 로컬 production build의 9개 경로를 320, 390, 768, 1024, 1440px와 light/dark 조합으로 확인했다. 90개 조합에서 문서 가로 넘침과 pageerror가 없었다.
- SDK 화면 캡처는 `assets/responsive-mobile-layout/`에 저장했다.
- 인증 및 백엔드 연동 검증은 포함하지 않았다.

## 복구 방법

이 변경의 commit을 revert한다. 데이터나 설정 migration은 없다.
